# Security Statement 

### Intended Users 
This repository is mainly intended for myself, my professor, and anyone involved in reviewing or grading my assignments. It contains code and projects that I have worked on throughout this class for educational purposes. 

### Security Risks 
I would consider the security risk of this repository to be relatively low since most of the code is just class assignments and doesn't contain sensitive information. However, there is still some risk if someone were to modify the code without permission or add malicious content. Another concern would be accidentally uploading personal information, passwords, or API keys into the repository. 

### Security Measures 
To help keep my repository secure, I created a GitHub ruleset called "Pull request approvals" that applies to the default branch. I enabled a few protections, such as preventing the branch from being deleted, blocking force pushes, and requiring pull requests before changes can be merged. These rules help prevent accidental changes and protect the code from being modified without going through the proper process. Since I'm the main person working on this repository, I kept the required approvals at zero and didn't set up a CODEOWNERS file. I also try to make sure that I don't upload any sensitive information like passwords or API keys.
